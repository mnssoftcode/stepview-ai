# StepView AI — Documentation Package

Start every serious coding session by reading `docs/06_AI_AGENT_RULES.md`, then the master/project documents it references.

Recommended implementation order:
1. Finish the documents.
2. Build a tiny labeled dataset.
3. Train a baseline.
4. Measure failures.
5. Add candidate placement logic.
6. Export to ONNX.
7. Build the web prototype.
8. Move the validated pipeline to mobile.

Do not begin by building the polished app UI.
